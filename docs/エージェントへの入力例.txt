  「触れ方の記憶」
  - Vector Searchで過去の触れ方パターンを記憶
  - 同じ部位を同じように触られると「覚えてる！」反応
  - 優しい触れ方の履歴が多いと親密度が上がる

  2. インタラクティブゲーム要素

  「感情シンクロゲーム」
  - エージェントが目標感情を提示（例: "joy=4にして！"）
  - ユーザーが触り方を調整してその感情値を目指す
  - 成功したら特別な振動パターンと音声で祝福

  「リズムゲーム風」
  - エージェントが振動パターンを出力
  - ユーザーが同じリズムで触れ返す
  - Leap Motionのタイミング検出を活用

  テストシナリオ

  このスクリプトは、同じ部位（頭）を2秒間隔で6回連続してタッチします：

  1. 1回目: 初めてのタッチ → 通常の反応
  2. 2回目: 2秒後 → 軽いくすぐったさ（レベル0-2）
  3. 3回目: 2秒後 → 中程度のくすぐったさ（レベル3-5）
  4. 4回目: 2秒後 → 中程度のくすぐったさ（レベル3-5）
  5. 5回目: 2秒後 → 強いくすぐったさ（レベル6-10）、「やめて〜！」
  6. 6回目: 2秒後 → 最大くすぐったさ（レベル6-10）

  期待される動作

  - エージェントは直近10秒以内の同部位タッチ回数をカウント
  - くすぐったさレベルに応じた振動パターンを生成
  - 回数が増えるほど強く速い振動パターン
  - 応答メッセージも「くすぐったい！」から「やめて〜！」に変化
